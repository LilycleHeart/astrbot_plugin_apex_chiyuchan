# 小赤羽 Apex 插件指令文档

## 战绩查询

**指令**: `/stats [玩家名]` 或 `/stats [@群友]` 或 `/stats [UID]`

查询 Apex Legends 玩家战绩并生成卡片图片。

**参数说明**:
- `玩家名` — 游戏内昵称，支持模糊搜索
- `@群友` — 查询群内绑定的玩家，避免同名搜索错误
- `UID` — 直接通过数字 UID 查询，最准确

**功能**:
- 显示段位、RP、排名
- 生涯击杀、总伤害、BR 胜场
- 常用英雄 TOP 3
- 当前选用英雄
- 段位分布参考
- RP 变动趋势（较上次查询）

**示例**:
```
/stats LilycleHeart
/stats @某人
/stats 123456789
```

## 账号绑定

### 绑定

**指令**: `/bind <玩家名> [平台]`

将 Apex 账号绑定到当前 QQ 号。

**参数说明**:
- `玩家名` — 必填，游戏内昵称
- `平台` — 可选，默认 PC。支持: PC, PS4, X1, SWITCH

**示例**:
```
/bind LilycleHeart PC
/bind LilycleHeart PS4
```

### 通过 UID 绑定

**指令**: `/bind_uid <UID> [平台]`

通过数字 UID 绑定账号，避免同名玩家导致绑错。

**参数说明**:
- `UID` — 必填，Apex 数字 UID
- `平台` — 可选，默认 PC

**示例**:
```
/bind_uid 123456789 PC
```

### 解绑

**指令**: `/unbind`

解除当前 QQ 号绑定的 Apex 账号。

## 地图轮换

**指令**: `/map`

查询当前 Apex 地图轮换信息。

**显示内容**:
- 匹配模式：当前地图、下一张地图、剩余时间
- 排位模式：当前地图、下一张地图
- 混合模式：当前地图和模式
- 外卡模式：当前地图

## 服务器状态

**指令**: `/server`

查看 Apex Legends 相关服务运行状态。

**显示内容**:
- 跨平台认证状态
- 大厅/匹配服务器状态
- PC 登录服务状态
- 玩家账户服务状态
- PSN/Xbox Live 状态
- 各区域延迟

## 找队友系统

**指令**: `/lfg <操作>`

群内找队友系统，按群隔离。

**操作类型**:
- `/lfg 排位` — 注册排位赛找队友
- `/lfg 娱乐` — 注册娱乐匹配找队友
- `/lfg 列表` — 查看当前群找队友列表
- `/lfg 退出` — 退出找队友列表

**显示信息**:
- 玩家名称
- 段位和 RP
- 等级和击杀数
- 在线状态
- 模式（排位/娱乐）

**说明**:
- 每个群独立的找队友列表
- 管理员可为他人注册/退出
- 战绩数据缓存 30 分钟

## 缓存管理

**指令**: `/cache <操作>`

管理插件的图片磁盘缓存。

**操作类型**:
- `/cache stats` — 查看缓存统计（目录、文件数、总大小）
- `/cache clear` — 清空所有缓存
- `/cache cleanup` — 清理超限缓存（保留最新，删除最旧）

**缓存说明**:
- 缓存目录: `assets/image_cache/`
- 图片永久保存，不会过期
- 最大缓存大小: 500MB
- 超限时自动清理最旧文件

## 常见问题

**Q: 查询不到玩家怎么办？**
A: 尝试使用 UID 绑定，或检查玩家名是否正确。

**Q: 数据不准确？**
A: 第三方 API 数据可能存在延迟，请以游戏内实际数据为准。

**Q: 图片加载失败？**
A: 检查网络连接，插件需要访问外网获取数据和图片资源。
